# 学习通逐键输入（开源版）

Windows 上的 AutoHotkey v2 脚本：读取当前剪贴板中的纯文本，按热键后分块模拟键盘输入到当前浏览器窗口。
它是输入辅助工具，不是浏览器扩展，也没有独立的复制功能；源文本仍需用户自行复制。

## 安装和使用

1. 从 [AutoHotkey 官方网站](https://www.autohotkey.com/) 获取 v2 运行时；本仓库不捆绑安装程序或可执行文件。
2. 双击 `学习通逐键输入.ahk`，托盘出现图标后生效。
3. 先在空白、可丢弃的文本框做测试；复制短文本，点击目标输入框，按 F9 开始。
4. F10 请求停止；切换到其他窗口时，脚本会在下一次检查处停止。停止后核对已输入的部分。
5. 退出时右键托盘图标选择 Exit；修改参数后选择 Reload。

## 默认行为

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| START_KEY / STOP_KEY | F9 / F10 | 开始 / 请求停止 |
| CHUNK / CHUNK_GAP | 30 / 15 ms | 每次输入字符数 / 块间延迟 |
| LINE_GAP / START_DELAY | 60 / 250 ms | 换行间隔 / 启动等待 |
| TAB_SPACES | 4 | 将 Tab 转成空格；设为 0 保留 Tab |
| GUARD_BROWSER | true | 仅在支持的浏览器窗口位于前台时开始 |
| ALIGN_INDENT | 0 | 默认不选择或改写自动缩进；设为 1/2 会选择或删除行首文本，需在空白编辑器先测试 |
| VERIFY | false | 默认不回读和自动删尾；开启后会全选复制，并可能退格删除末尾额外字符 |
| BEEP / TIP | true / false | 提示音 / 托盘提示 |

原公开准备版关闭了可能改变已有文字的高级校验；高音只表示流程结束，不证明逐字正确。
编辑器的自动缩进、括号补全、输入法和浏览器快捷键都可能影响结果，需要人工核对。

## 使用边界

- 全局 F9/F10 可能与其他软件冲突；可修改脚本顶部的 START_KEY / STOP_KEY，重载后生效。

- 仅在你有权输入且允许使用辅助工具的场景使用，不承诺规避平台规则、检测或考试限制。
- 默认只检查浏览器进程和原窗口，无法确认当前标签页、输入框或是否为学习通；同一窗口切换标签页/焦点不会被可靠识别。输入过程中保持目标焦点，提前清理目标框并先备份重要内容。
- F10 与窗口检测不能撤回已经发送的按键；编辑器已有选区可能被输入内容替换。
- 脚本不自动发送最终提交，但模拟 Enter 仍可能触发某些网页的表单行为。请先用无提交行为的测试框验证。
- 不需要管理员权限；不要为此脚本修改系统安全或浏览器安全设置。

## 验证、隐私与许可

可使用 AutoHotkey v2 的 `/Validate` 配合 `/ErrorStdOut=UTF-8` 只加载检查而不运行脚本。
语法通过不证明真实编辑器兼容或输入无误。详见 [PRIVACY.md](PRIVACY.md)。
脚本代码采用 MIT；AutoHotkey 运行时遵循其自身许可证。没有捆绑用户剪贴板内容或本机操作记录。
